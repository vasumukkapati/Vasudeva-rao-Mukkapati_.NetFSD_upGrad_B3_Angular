Frequently Asked Questions

1. What is jQuery?
jQuery is a lightweight JavaScript library used for DOM manipulation and event handling.
2. What is slideToggle()?
slideToggle() smoothly shows or hides elements using a sliding animation.
3. What is DOM manipulation?
DOM manipulation means dynamically modifying HTML content using JavaScript or jQuery.
4. What is event handling?
Event handling allows execution of code when user interactions occur.
5. Why use Bootstrap?
Bootstrap provides responsive design and pre-built UI components.
